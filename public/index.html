Using it in DaVinci / Adobe

Premiere / After Effects: import the .mov and drop it on a track above your footage. Transparency is detected automatically.

DaVinci Resolve: import the .mov and place it on V2. If edges look dark, right-click the clip → Clip Attributes → Alpha mode → Straight.

PNG sequence: unzip, then import the first frame as an image sequence. It works in every app and needs no server.
